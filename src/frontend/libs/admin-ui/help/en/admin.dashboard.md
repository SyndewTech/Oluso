Welcome to the Admin Portal. This dashboard gives you an at-a-glance overview of your identity and access management environment.

## Quick Actions

- **Add a Client** to register a new application
- **Invite a User** to grant someone access
- **Review Audit Logs** to see recent activity

## Navigation

Use the sidebar on the left to navigate between sections. The sidebar groups related pages under expandable menus:

- **Applications** - Manage OAuth/OIDC clients, API resources, and scopes
- **Federation** - Configure external identity providers (SAML, OIDC)
- **User Management** - Users, roles, and grants
- **Experience** - User journeys, data collection, and plugins

## Module Plugins

If your organization has enabled additional modules, they appear in the sidebar automatically. Each module adds its own admin pages for configuration.
