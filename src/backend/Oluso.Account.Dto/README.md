# Syndew.Oluso.Account.Dto

Wire-contract DTOs for the Oluso Account module. Shared by backend controllers and mobile clients.

You don't usually install this package yourself: it comes with `Syndew.Oluso.Account`. Reference it directly from a client that calls the account API and wants the same request and response types.
