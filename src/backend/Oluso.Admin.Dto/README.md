# Syndew.Oluso.Admin.Dto

Wire-contract DTOs for the Oluso Admin module. Shared by backend controllers and frontend clients.

You don't usually install this package yourself: it comes with `Syndew.Oluso.Admin`. Reference it directly from a client that calls the admin API and wants the same request and response types.
