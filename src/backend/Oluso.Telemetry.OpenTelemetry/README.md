# Syndew.Oluso.Telemetry.OpenTelemetry

OpenTelemetry implementation for Oluso telemetry. Provides metrics, tracing, and logging via the OpenTelemetry standard.

The admin portal's telemetry pages are `@syndew/oluso-plugin-telemetry` on npm.

## Install

```bash
dotnet add package Syndew.Oluso.Telemetry.OpenTelemetry
```

## Use

```csharp
builder.Services.AddOlusoOpenTelemetry();
```
