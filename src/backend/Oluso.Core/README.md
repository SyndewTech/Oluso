# Syndew.Oluso.Core

Core abstractions and domain entities for Oluso identity server.

The domain entities, store interfaces, events, options and services that the Oluso server and its modules are built on. Reference it from code that extends Oluso: custom stores, journey steps, event sinks or modules.

## Install

```bash
dotnet add package Syndew.Oluso.Core
```

To run an identity server, install `Syndew.Oluso`, which brings this in.
