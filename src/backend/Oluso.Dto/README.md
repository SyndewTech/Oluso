# Syndew.Oluso.Dto

Wire-contract DTOs for the Oluso platform module. Shared by backend controllers and mobile clients.

You don't usually install this package yourself: it comes with `Syndew.Oluso`. Reference it directly from a client (for example a .NET or MAUI app) that calls the Oluso platform API and wants the same request and response types.
