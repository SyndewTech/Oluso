# Syndew.Oluso.Enterprise.Cloudflare

Cloudflare integration for Oluso identity platform. Provisions custom tenant domains via Cloudflare Custom Hostnames API (SSL for SaaS).

## Install

```bash
dotnet add package Syndew.Oluso.Enterprise.Cloudflare
```

## Use

```csharp
builder.Services.AddCloudflareCustomHostnames();
```
