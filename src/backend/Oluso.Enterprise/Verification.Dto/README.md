# Syndew.Oluso.Enterprise.Verification.Dto

Wire-contract DTOs for Oluso business (KYB) verification. Shared by backend controllers and clients.

You don't usually install this package yourself: it comes with `Syndew.Oluso.Enterprise.Verification`. Reference it directly from a client that calls the verification API.
