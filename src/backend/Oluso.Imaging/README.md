# Syndew.Oluso.Imaging

Image resizing for Oluso public assets, behind IImageResizer. The default implementation uses SkiaSharp and mirrors Cloudflare Image Resizing's options.

## Install

```bash
dotnet add package Syndew.Oluso.Imaging
```

## Use

```csharp
builder.Services.AddImageResizing();
```
